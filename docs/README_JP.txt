ZIP FORMULA RACINGDASH - インストールガイド
==================================================

【インストール】

1. SimHubを終了します。
2. ZipFormula-SimHub-Setup.exeを実行します。
3. インストール完了後、SimHubを起動します。
4. Dash Studioを開き、「Import Dashboard」を選択します。
5. ドキュメント内の「Zip Formula\SimHub Dashboard」フォルダーにある .simhubdash ファイルを選択します。

【重要】
.simhubdashファイルをフォルダーに配置しただけでは、SimHubにダッシュボードは登録されません。
必ずDash Studioの「Import Dashboard」からインポートしてください。

【アンインストール】
Windowsの「インストールされているアプリ」からアンインストールできます。
ダッシュボードとライセンスファイルはドキュメントフォルダーに残ります。
不要な場合は手動で削除してください。

インストール前から同名のPostItNoteRacingプラグインファイルが存在した場合、アンインストール時にバックアップから復元します。
